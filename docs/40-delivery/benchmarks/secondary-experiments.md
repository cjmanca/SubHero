# B6+ — Metadata, scoring, glossary, OCR, Plex and filesystem experiments

**Status: later / not run.** Separate from the initial B0+B1 synchronization proof. This page is a **routing checklist**, not an instruction to build these features before the core algorithm gates. Each experiment loads its **own owning requirement file**, not all of the subtitle pipeline.

| Experiment | Competing hypotheses / controlled case | Mandatory observable outcome | Requirements owner |
| --- | --- | --- | --- |
| M1 — Audio language | Several distributed speech-rich samples, sample count/length, primary language vs mixed-language intros | Per-track dominant-language precision and safe abstention; errors overriding known labels vs filling `und` | [Track metadata](../../10-media/track-metadata-and-classification.md) |
| M2 — Subtitle metadata | Dominant language of normal + karaoke mixed scripts; full vs forced signs/song subsets; commentary, dub-matched and SDH tracks | Wrong forced/commentary classification and missed corrections **both** counted; use same-language audio context for forced selection | [Track metadata](../../10-media/track-metadata-and-classification.md) |
| M3 — OCR | PGS/VobSub rendered text and positioning versus approved text/positions; OCR as independent queue job | Text recovery, language accuracy, cue timing/layout retention; `unassessed` when OCR cannot resolve | [Bitmap OCR](../../20-subtitles/bitmap-ocr.md) |
| G1 — Series terminology | User-confirmed vs inferred entries; term counts, source text, independent source groups, trusted release-group priors; scan unprocessed episodes before enhancement | Accuracy, terminology consistency and false retroactive changes; human conflicts; layout/CPS after replacement | [Glossary](../../20-subtitles/series-glossary.md) |
| Q1 — Quality and opportunity | Best single full track vs hypothetical merge; assess dimensions available vs unavailable; predict improvements before actual enhancement | Compare predicted `potential - best existing` to **measured improvement** on held-out data at **matched scoring coverage**; evaluate priority ranking/calibration | [Quality](../../30-app/quality-and-triage.md) |

| P2 — Plex flags/audio | Track ordering, commentary/original/default/forced and channel layout; Linux `FlagCommentary=1` regression scenario | Actual playback/scanner behavior on **tested versions only**; false assumptions recorded | [Plex/sidecars](../../10-media/plex-and-sidecars.md) |
| O1 — Unraid publication | Scratch same logical `/mnt/user` path but different backing disk/pool; reflink/full copy, hardlinked originals, stale source/Tdarr rename | **No missing/partial media-visible interval**, preservation or intentional break of hardlinks, no stale commit, rollback and scan behavior | [Safe writes](../../10-media/safe-media-writes.md) |
| O2 — Sidecar naming/provenance | Filename collision, release-group qualifiers, Bazarr coexistence, Tdarr stripped title/tags, normalized cue fingerprints | Correct language discovery, no accidental duplicate/reprocessing, explicit unknown provenance when identity ambiguous | [Output/provenance](../../20-subtitles/output-and-provenance.md) |

All cross-filesystem/atomic tests must use **disposable test media**, not real library files. A successful `os.replace` on one fixture is not proof of atomic behavior across every Unraid disk/pool/SHFS combination. Distinguish observed reproducible behavior from guarantees of the application. Avoid proprietary cloud-media uploads without explicit user consent and costs recorded.

SDH→ordinary stripping can be tested independently for preservation of dialogue; generating reliable full SDH from ordinary subs is **not** a first-phase goal. Background dialogue/source separation and speaker-on-screen positioning remain **late, opt-in experiments**.

When these domains become active, split a growing experiment into a focused protocol without copying its functional requirements here. Use [shared metrics](evaluation-criteria.md) and record decisions in [findings](findings.md).
