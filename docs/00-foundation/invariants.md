# Cross-cutting safety and quality invariants

**Always read for media writes or corrections.** Detailed mechanics: [safe writes](../10-media/safe-media-writes.md), [output](../20-subtitles/output-and-provenance.md), [review](../30-app/web-ui-and-review.md).

1. **No avoidable regression.** Existing valid translations, timing, fonts, positioning, song/sign effects, track languages and media streams must not be degraded merely to increase the number of changes. Uncertain findings remain unmodified suggestions/review items.
2. **Preserve source evidence.** Keep original subtitle text/timestamps/styles/track identity separately from measured audio and proposed corrections. Normal enhancement NEVER overwrites original subtitle text. Direct retiming of originals is an explicit opt-in, recorded for rollback.
3. **Generated tracks are additions/replacements of prior generated tracks.** Lightweight and full enhancement produce an identifiable generated subtitle track. Later passes replace that generated output, preserve approved decisions/history, and avoid using it as an independent human reference.
4. **Evidence-based time.** LLMs can assess semantics, not invent final timestamps. Use measured audio alignment, source timeline mappings and deterministic subtitle scheduling; preserve uncertainty by region/event.
5. **No blind synchronization.** ffsubsync, ALASS, and model-generated alignments are hypotheses until verified. Retain unchanged regions when verification fails. Signs, song lyrics, and non-speech cues must never serve as ordinary spoken-dialogue anchors.
6. **No premature publication or non-atomic visible replacement.** Unapproved subtitle drafts must remain outside Plex-watched locations unless the user explicitly authorizes a live preview. Plex/library clients should never observe a missing or partially copied media file. Validate staged outputs and source identity before commit. Abort if atomic replacement cannot be guaranteed or safely demonstrated.
7. **Filesystem and other applications matter.** Default target is final library (not torrent download area); hardlinks, Unraid `/mnt/user`, Tdarr replacement, Bazarr-managed sidecars, and Plex filesystem watching must be handled deliberately.
8. **Bounded, configurable autonomy.** Separate analysis depth from mutation/approval policy. Permit automatic high-evidence changes per operation; flag contradictory/unsafe changes. Model percentages are not automatically calibrated probabilities.
9. **Explicit lineage and reversibility.** Track corrections, model versions, approval status, sidecar or embedded identity, input fingerprint, and revision history; keep rollback available. Provenance may be partially lost after third-party transcoding—do not infer certainty.
10. **Capability-aware degradation.** If an aligner, target-language model, OCR processor, renderer, or output format lacks a capability, report limitations and choose safe fallback/review—not a fabricated result or silent omission.
11. **No unnecessary heavyweight processing.** Cache transcripts, matches and decisions with correct dependency invalidation; discard extracted audio by default after processing. Escalate costly inference selectively.
12. **Least privilege.** File mutation, approval, model execution, external cloud disclosure, and admin controls require explicit authorization/ACL; never expose uncontrolled library filesystem actions through an API or MCP agent.
